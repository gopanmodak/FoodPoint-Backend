# 🍔 FoodPoint Backend

## 📌 Overview
FoodPoint Backend is a Node.js + Express server that connects to MongoDB Atlas for managing data.  
It includes modular database connection logic and supports CRUD operations.

---

## 🚀 Tech Stack
- Node.js  
- Express.js  
- MongoDB Atlas  
- dotenv (for environment variables)
